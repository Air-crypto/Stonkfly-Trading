# Fly circuit debugger

The debugger records the actual full retained network at the controller's 10 ms
integration boundary. It does not replace the native integrator, prune the graph,
or write to a paper account. The current diagnostic backend runs locally;
the scheduled paper traders still run on Modal independently.

![Interactive circuit and input controls](assets/fly-debugger.png)

## Open the included recordings

From the repository root after the normal locked install:

```sh
uv run python -m paperlab.debugger serve --out examples/fly-debugger
```

Open <http://127.0.0.1:8765>. No credentials, graph download, or ongoing model
compute are needed to view the included recordings. Choose `fall_learning`,
observation 3, and compare `fall_frozen` to see the action disagreement.
The examples contain real full-network activity driven by synthetic inputs.
They contain no account data. Full-neuron lookup requires the larger NPZ files,
which are generated by the commands below and excluded from Git.

## Run and inspect new inputs

Prepare the retained graph once (Python 3.12, C++ compiler, about 1.1 GB of source
downloads, and sufficient memory; plan for 16 GB RAM). Then:

```sh
uv run paperlab fly-prepare --fly-data data/fly
uv run python -m paperlab.debugger study --fly-data data/fly --out runs/study-01 --steps 4
uv run python -m paperlab.debugger serve --fly-data data/fly --out runs/study-01
```

The server binds to loopback and runs one submitted assay at a time. The form
starts an isolated subprocess and displays its progress log. Test rising,
falling, flat, reversal, or shock prices; change plasticity and eta; supply
synthetic news; ablate the header/news strip or the entire image; or inject
bounded current into up to 16 exact retained neuron IDs. All assays start from
pristine native state. A new assay never continues or rolls back the deployed
trader's checkpoint. Closing this local server closes access to this debugger,
but does not affect Modal's scheduled traders.

For one CLI capture:

```sh
uv run python -m paperlab.debugger capture --fly-data data/fly --out runs/custom/capture-01 --preset fall --steps 4 --frozen
uv run python -m paperlab.debugger serve --out runs/custom
```

`capture --config config.json` accepts the complete `Assay` configuration:

```json
{
  "preset": "rise", "steps": 4, "learning": true, "eta": 0.001,
  "reinforcement": "none", "view": "original", "news": "none",
  "neurons": [], "current": 0
}
```

Observation count is bounded to 1–8; each observation is 500 ms of neural time.
Extra stimulation lasts the whole observation. Reinforcement stimulates the
identified reward or aversive cells for the unchanged first 200 ms. These are
engineered interventions, not proof that the network recognizes market outcomes.
The `price_only` ablation removes the header and lower strip; it still retains
the original chart grid, scaling, colors, and the same cropped price region.

## What the views mean

- **Neuron activity:** actual bin spike counts. The voltage plot shows voltage
  at each bin boundary; it does not resolve individual 0.1 ms spike waveforms.
- **Connection activity:** a recorded presynaptic neuron spiked. A highlight
  does not prove transmission, a postsynaptic spike, or causal influence.
- **Amber connections:** plastic weight differs from its value at the start of
  the selected observation. The edge inspector shows exact endpoints and weight.
- **Learning:** L2 weight displacement, changed-edge count, KC/DAN rate traces,
  memory states, and clipping. Optimizer loss and backprop gradients are `null`
  because this rule has neither; the UI never invents them.
- **Decoder:** whole-observation mean DNp20 firing rates, DNpe017 gate spikes,
  and the fixed BUY/SELL/HOLD mapping. A positive rate difference still produces
  HOLD if the gate does not spike.
- **Graph:** the native computation uses all 166,700 neurons and 25,582,938
  directed connections. The view selects the most active 18 visual and 48 KC
  cells, identified DAN/MBON/output cells, and requested stimulation IDs.
  Connections are actual graph edges between displayed endpoints. Missing
  intermediate neurons can make visual or decoder groups appear disconnected.
  Functional column positions are not anatomical coordinates.

Every observation produces `step-NN.npz` with **all** neuron IDs, counts, voltages,
all 7,835 plastic edges, bin weights, KC/DAN traces, and memory states; an exact
input PNG; and a report with native/source hashes. `view.json` is a bounded
rendering export. The input hashes allow checking identical sensory input across
arms. Use the exact-ID lookup against full recordings to inspect cells outside
the default view. Native checkpoints remain platform/build dependent.

## First controlled study

The [predeclared protocol](../reports/fly-debugger-protocol-01.json) has eight
arms, four observations each, identical pristine initial state per arm, and no
selection by profitability. The [complete results](../reports/fly-debugger-study-01.json)
include every arm, all decoder values, spike hashes, and learning diagnostics.

| Comparison | Different actions / 4 | Observed implication |
| --- | ---: | --- |
| Rising prices: learning vs frozen | 0 | Activity changed; action sequence did not |
| Falling prices: learning vs frozen | 1 | Plasticity affected a downstream action |
| Rising vs falling prices, learning | 2 | Sensory input affects later decisions |
| Reward vs aversive pulses | 0 | Distinct reinforcement changed spikes, not these actions |
| Default vs 10× lower eta | 0 | Lower eta alone did not change these actions |
| Original vs header/news-strip removal | 1 | Non-price display regions can change a decision |

In the falling-price arm, observation 3 was BUY with learning and HOLD frozen.
The learned gate spiked once; the frozen gate did not spike. A rising chart and
a falling chart both began with BUY. These observations identify decoder gating,
input encoding, and credit assignment as subjects for further tests. They do not
show that every falling market should produce SELL or establish an improved
trading strategy. The assays execute **no trades** and measure no financial return.

Four observations cover only two seconds of neural time. This is a deterministic
mechanics study on fixed synthetic inputs, without a statistical performance
claim. The native verification checks that instrumentation preserves the
unrecorded spike/memory result, reset reproduces it, and frozen weights do not
change. Run it explicitly with a prepared graph:

```sh
FLY_TRACE_DATA=data/fly uv run python -m pytest tests/test_fly_trace.py -q
```

Further improvement work must compare frozen and learning policies on the same
chronological market observations, with next-observation fills and fees, slippage,
spread, unavailable inventory, and untouched validation windows. Do not deploy an
assay winner or reverse a live account merely because a visualization looks better.
